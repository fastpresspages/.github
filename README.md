# FastPress Labs community files

This repository powers the [FastPress Labs organization profile](https://github.com/fastpresspages) and provides default community health files for its projects.

- [`profile/README.md`](profile/README.md) — the public organization profile
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to contribute across projects
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — Contributor Covenant 2.1
- [`SECURITY.md`](SECURITY.md) — private vulnerability reporting
- [`SUPPORT.md`](SUPPORT.md) — where to ask for help
- [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) — default issue forms
- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) — review checklist

The main project is [LaunchGrade](https://github.com/fastpresspages/launchgrade): a zero-dependency launch page grader with a CLI, GitHub Action, MCP server and agent skill.

Nothing here should claim a metric, partnership or endorsement that cannot be shown in public. See [CONTRIBUTING.md](CONTRIBUTING.md).
